## Why this card exists

After CARD-322 the interior is written as PDF operators on every production path, and nothing in production calls the 23 raster interior writers or the bitmap arms of `interior_stream`. They stay only as a reference oracle and as the subject of about 390 tests. The owner's rule (2026-11-07): a test is kept only if its claim is still a live product decision; no tests for the sake of tests. CARD-322's claim audit (`~/Documents/nonogram-reviews/CARD-322/CLAIM-AUDIT.md`) classifies the 390 node ids: LIVE (32 plain, 36 pending CARD-233's tile header), LIVE with a raster-specific instrument (15, PIL `ImageDraw.text` spies), LIVE-UNVERIFIED (251, decision stands per cards and git, vector page not checked), RASTER-ARTEFACT (28, plus 27 candidates, the dot arm), UNKNOWN (1). The measured prototype: pointing the page-obtaining helper at the vector render lets about 57 of 83 node ids in `test_book_solved_page` and `test_book_toc` pass unchanged (~69%); the reds there were raster-specific spies (15), raster comparators (8) and one real difference (the grey boundary, ruled correct), none a claim the vector page fails.

## What to implement

Work in MODULE BATCHES, each its own commits, each checked green before the next. The first batch (`test_book_solved_page` and `test_book_toc`, the two modules the prototype measured) re-prices this card: STOP and report if it costs more than 3c.

0. **Re-derive.** Re-run the classifier on the tree you start from; compare with the audit (390 ids over 28 modules, 14 `test_puzzle_solver_clues` ids excluded as their own `_blank_page` users, 2 name collisions to resolve: one id each in `test_admin_tier_surfaces` and `test_book_scaffolding`). A different number is the finding.
1. **Per module: point the page-obtaining helper at the vector render** (the existing poppler rasteriser `page_image`, the stream writers `answer_page_stream`, `toc_page_stream`, the other `*_stream` functions) and keep every assertion as written. Where the instrument is raster-specific (a spy on `ImageDraw.ImageDraw.text`), re-express it with the `pdf_vector` readers; where the comparator is a raster reference, switch the reference to the vector render. A red that is a real vector/raster difference is a finding to report, not a test to retire: the live decision wins (CARD-322's audit found none beyond the ruled grey boundary).
2. **Retire only on evidence.** A claim the owner reverted or superseded (cite the commit, card or ADR), or a claim about the bitmap medium itself, is retired with the evidence in the commit message and a plant-checked survivor for anything still live. An UNKNOWN goes to the owner: list it, do not decide it. Pending CARD-233's header rewrite does not retire a claim today.
