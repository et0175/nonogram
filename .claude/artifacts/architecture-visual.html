All capabilities operate on a single aggregate (Puzzle) within CTX-001 bounded context. One-way dependency flow: no lateral imports between capabilities.

🔄 Request Flow: Browser → Python Core
1. Form Submission - Browser form with grid parameters, difficulty, export formats
2. API Handler - api/generate.py receives POST with multipart/urlencoded data
3. Form Parsing - submission.py extracts fields, validates against GenerationRequest
4. Image Upload - multipart.py handles file upload, resize, Floyd-Steinberg dithering (if needed)
5. Orchestration - orchestrator.generate() runs sourcing → clues → solver → difficulty → export pipeline
6. Uniqueness Check - solver verifies exactly one solution; auto-retry/nudge on failure
7. Export - Generates PNG/SVG/JSON/CSV/PDF based on requested formats
8. Response - Returns JSON with file paths; temporary image file cleaned up
9. Download - Browser receives paths, initiates file downloads
