**Дата:** 2026-09-06

## I. Огляд Проекту

### Цільова аудиторія
- **Первинна:** Люди похилого віку (55+)
- **Вторинна:** Усім, хто любить нонограми
- **Формат:** Друковані книги + веб-платформа

### Основна бізнес-модель
1. **Книги на Amazon KDP** - 200 нонограм на Рождественську тему
2. **Веб-платформа** - Користувачі можуть генерувати нонограми з власних фото
   - Безплатно: 3 нонограми/місяць (потім підписка)
3. **Адмін-панель** - Управління каталогом, затвердження головоломок, генерація книг

## IV. Вимоги до Функцій

### **4.1 Калькулятор Сложності**

**Вхідні дані:**
- Нонограм (сітка + clues)
- Розмір
- Кількість заповнених клітинок (density)

**Вихідні дані:**
```
{
  "difficulty_score": 1-100,      # Числовий бал
  "difficulty_tier": "Easy|Medium|Hard",
  "strategies_used": ["line_logic", "pointing_pairs", ...],
  "strategy_count": 8,
  "backtracking_depth": 2,
  "estimated_solve_time_seconds": 45
}
```

**Алгоритм:**
- Аналіз стратегій (див. solving_techniques.md)
- Підрахунок унікальних прийомів
- Оцінка глибини backtracking
- Визначення Tier (Легко < 30, Середньо 30-70, Важко > 70)

### **4.2 Метрика Якості Зображення**

**Вхідні дані:**
- Оригінальне зображення
- Сгенерований нонограм

**Вихідні дані:**
```
{
  "quality_score": 1-100,         # Наскільки близько до оригіналу
  "visual_similarity": 0.85,      # % подібності
  "recognizability": "high|medium|low"  # Чи впізнавання зображення
}
```

**Критерії:**
- Збереження основних деталей
- Чіткість силуету
- Розпізнаваність для користувача

### **4.3 Адмін-панель: Генерація Партії**

**Вхідні параметри:**
- Кількість нонограм (50-200)
- Розміри (10×10, 20×20, 30×30 або мікс)
- Тема (Рождество, Новий Рік, etc)
- Джерело: Random / From Images / Library
- ДFilter: Only high-quality (> 70 score)

**Вихід:**
- Таблиця з 100+ нонограм
- Превью для кожного
- Метрики (сложність, якість)
- Галочка "Додати в книгу"

### **4.4 Генерація PDF Книги**

**Вхідні дані:**
- Список вибраних нонограм (200+)
- Метаданих книги (назва, тема, обкладинка)
- Параметри: сторінка A4, 1-2 нонограми на сторінку
- Розв'язки (опціонально в кінці)

**Вихід:**
- PDF готовий до Amazon KDP
- Форматування: шрифти, вирівнювання, spacing
- Нумерація сторінок
- Індекс сложності

## V. Схема Бази Даних

```sql
-- Таблиця користувачів
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email VARCHAR UNIQUE,
  subscription_tier VARCHAR, -- 'free', 'premium'
  puzzles_generated_month INT,
  created_at TIMESTAMP
);

-- Таблиця нонограм
CREATE TABLE nonograms (
  id UUID PRIMARY KEY,
  name VARCHAR,
  theme VARCHAR,           -- 'christmas', 'newyear', etc
  width INT,
  height INT,
  difficulty_score INT,    -- 1-100
  difficulty_tier VARCHAR, -- 'Easy', 'Medium', 'Hard'
  quality_score INT,       -- 1-100 (оригіналу до нонограму)
  strategies_used TEXT[],  -- JSON array
  solution_grid TEXT,      -- JSON array
  clues_rows TEXT,         -- JSON array
  clues_cols TEXT,         -- JSON array
  image_source_url VARCHAR,-- оригінальне зображення
  created_at TIMESTAMP,
  status VARCHAR           -- 'draft', 'approved', 'in_book'
);

-- Таблиця книг
CREATE TABLE books (
  id UUID PRIMARY KEY,
  title VARCHAR,
  description TEXT,
  theme VARCHAR,
  target_audience VARCHAR,  -- 'seniors', 'general'
  nonogram_ids UUID[],      -- список ID нонограм
  cover_image_url VARCHAR,
  pdf_url VARCHAR,
  page_count INT,
  status VARCHAR,           -- 'draft', 'ready', 'published'
  kdp_asin VARCHAR,         -- Amazon book ID
  created_at TIMESTAMP
);

-- Таблиця історії генерацій
CREATE TABLE generation_history (
  id UUID PRIMARY KEY,
  user_id UUID,
  puzzle_id UUID,
  image_url VARCHAR,
  timestamp TIMESTAMP
);

-- Таблиця книг користувача (вибрані)
CREATE TABLE user_selected_books (
  user_id UUID,
  puzzle_id UUID,
  book_id UUID,
  selected_at TIMESTAMP,
  PRIMARY KEY (user_id, puzzle_id, book_id)
);
```
