{# The manual puzzle editor (CARD-246) — the page the owner paints a stored puzzle's grid on, reached from the puzzle list and from a puzzle's own card. It is the PLAYER'S BOARD, a second time. There is one grid renderer in this panel (static/solver.js) and this page loads it, exactly as puzzle_solve.html does, with the same payload plus "mode": "edit" — the one flag solver.js reads (its EDIT MODE section is the contract). A second renderer is what CARD-246 G-2 forbids, for the reason ADR-0036/R3 gives for round marks: two implementations of one picture drift. So the markup below is puzzle_solve.html's, minus the parts that are statements about a SOLUTION — the error and progress counters, the hint counter, the Hint button and the solved banner. In edit mode the grid being painted IS the solution, so an error count would count departures from the grid the owner is changing and the solved lock would fire before the first stroke. solver.js leaves all of them off behind the same flag and asks for none of their elements. What stays, and is the player's own code unchanged: the brush trigger and its menu, the Region toggle (aria-pressed, CARD-211), the visually hidden role="status" announce line every toggle and every hint writes to, undo, redo, reset with its role="alertdialog" confirmation, and zoom. The toolbar starts hidden and solver.js shows it once the board is drawn, so a page whose script never ran shows no dead buttons. TWO BRUSHES, not four. Black and White are the only marks an answer can hold — Puzzle.grid is list[list[bool]] (ADR-0012) — so Maybe and Undecided are not offered here. That is a NARROWING OF THE TOOLS AND NOT A GUARANTEE, and the difference matters: a repeat click's third step is "blank" for both remaining brushes (solver_state.js clickedState) and a confirmed Reset blanks every cell, so an undecided cell is still reachable. CARD-246 AC-6's rule is therefore the refusal in static/puzzle_edit.js — Save names the undecided cells and sends nothing — and the usage hint below says so. THE SAVE BAR is this page's own (#puzzle-editor, static/puzzle_edit.js): Save, then the owner's two-phase confirmation. #puzzle-editor-message is a role="status" line that is ALWAYS present and never hidden (a live region that only appears is not reliably read), and the Approve/Cancel pair (#puzzle-editor-decide) is what appears and disappears — hidden until a grid has been verified, and hidden again on a refusal, so a grid that may not be stored is never shown an Approve button (AC-5).
